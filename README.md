# BLOOM 🌸

A cute, girly, interactive daily wellness tracker built with Next.js and browser local storage. No backend, no database, no paid services.

## Features

- Daily wellness and productivity tracker
- Mobile-first pastel UI
- Theme switcher with multiple pretty palettes
- Smooth motion and slide-animated interactions
- Local storage persistence in the browser
- Streak tracking and Bloom Garden concept
- Wellness score and automatic productivity status
- Vercel-ready deployment

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the repo into Vercel
3. Choose the default Next.js settings
4. Deploy

No database or backend is required because the app stores everything in the browser using localStorage.

## Notes

This app is built for a single user and is intentionally simple, cute, and free to run.
